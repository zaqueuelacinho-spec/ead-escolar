# EAD Escolar

Plataforma de Ensino a Distância para o ensino secundário, baseada no protótipo Figma **EAD Escolar — Protótipo TCC**.

## Perfis
- Aluno
- Professor
- Administrador

## Estrutura inicial
O projeto foi organizado para uma implementação web responsiva mobile-first, com autenticação, disciplinas, aulas, trabalhos, materiais, notas e administração.

## Próximos módulos
- Frontend React + TypeScript
- Supabase Auth e PostgreSQL
- Controlo de acesso por perfil
- Materiais e submissões
- Notas e desempenho
- Relatórios administrativos
