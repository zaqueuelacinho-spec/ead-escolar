# Arquitetura

## Frontend
React + TypeScript + Vite, com abordagem mobile-first e componentes reutilizáveis.

## Backend
Supabase Auth + PostgreSQL + Storage + Row Level Security.

## Dados principais
profiles, classes, subjects, enrollments, lessons, materials, assignments, submissions, grades e notifications.

## Segurança
O acesso deverá ser condicionado ao perfil autenticado. Alunos acedem aos seus dados académicos; professores gerem as suas turmas e avaliações; administradores gerem a plataforma.
